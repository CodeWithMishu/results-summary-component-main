### What I learned

This challenge reinforced how to build a responsive card layout that changes from a two-column desktop view to a stacked mobile layout.

One of the main things I focused on was using a media query to adjust the layout cleanly on smaller screens, especially by changing the container structure and border radius so the design still feels like one connected component.

### Continued development

I want to keep improving how I handle responsive spacing and card layouts so small screen adjustments feel more intentional. I also want to keep practicing cleaner CSS organization as projects get a little larger.
